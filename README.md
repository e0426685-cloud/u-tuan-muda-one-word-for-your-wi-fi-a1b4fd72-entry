## The entry

One word: **Ghosting**.

Home Wi-Fi that vanishes mid-call, mid-show, mid-sentence — exactly when you
need it most — then drifts back like nothing happened. The network ghosts you.

## How it works

`main.py` (Python 3.13, standard library only) validates the word against the
competition gate (a single word, 1–20 characters) and writes it to
`/output/entry.txt` with mode `0644` so the grader can read it.

```sh
python3 main.py
cat /output/entry.txt
```
